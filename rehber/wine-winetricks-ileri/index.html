Z Kitap Hâlâ Açılmıyor 3 (İleri Düzey Çözüm)

Sistem
Windows Karşılığı: DirectX / DLL Hatası
Eğer 32-bit desteğini kurmanıza rağmen program açılmıyorsa, eksik parçaları (DirectX, Fontlar) tamamlamanız gerekir.
1. Adım (Kurulum): Uçbirim'i açın ve şu komutu yapıştırıp Enter'a basın:

sudo apt install winetricks
2. Adım (Açma): Kurulum bitince Uçbirim'e şu komutu yazıp Enter'a basın:

winetricks --gui
3. Adım (Yükleme): Karşınıza çıkan pencerede şunları yapın:
a. Select the default wineprefix seçeneğini seçin.
b. Install a Windows DLL or component seçeneğine tıklayın.
c. Listeden d3dx9, mfc42 ve vcrun2015 kutucuklarını işaretleyip 'OK' butonuna basın.
