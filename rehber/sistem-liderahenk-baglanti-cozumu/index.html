LiderAhenk'te Görünmeyen Tahta Çözümü

Sistem
Windows Karşılığı: Uzaktan Yönetim / Merkezi Kontrol Sorunu
Etkileşimli tahtanız merkezi yönetim sisteminde (LiderAhenk) görünmüyorsa, istemci servisini tazeleyerek bağlantıyı yeniden kurabilirsiniz.
1. Adım: Uygulama menüsünden Uçbirim (Terminal) uygulamasını açın.
2. Adım: Mevcut ahenk paketini sistemden tamamen kaldırmak için aşağıdaki komutu yazıp Enter'a basın (Şifre yazarken görünmeyecektir):
sudo apt purge ahenk
3. Adım: Kaldırma işlemi bittikten sonra servisi temiz bir şekilde yeniden kurmak için şu komutu çalıştırın:
sudo apt install ahenk
4. Adım: Kurulum tamamlandığında uygulama menüsünden ETA Kayıt uygulamasını açın ve tahtayı bilgilerini girerek sisteme tekrar kaydedin.
