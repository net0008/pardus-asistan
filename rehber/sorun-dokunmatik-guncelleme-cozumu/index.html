Windows Karşılığı: Dokunmatik Ekran Sürücüsü Onarma / Touchscreen Fix
Bazı etkileşimli tahtalarda güncelleme sonrası dokunmatik özelliğinin çalışmaması, sistemde kalan eski beta sürücülerinden kaynaklanabilir.
Bu sorunu çözmek için öncelikle Uçbirim (Terminal) uygulamasını açın.
1. Adım: Paket listesini güncellemek için şu komutu çalıştırın:
sudo apt update
2. Adım: Test aşamasından kalan eski beta paketini sistemden tamamen kaldırmak için:
sudo apt purge eta-touchdrv
3. Adım: Güncel ve stabil dokunmatik sürücüsünü yeniden kurmak için şu komutu girin:
sudo apt install eta-touchdrv
Kurulum bittikten sonra sürücünün devreye girmesi için tahtayı yeniden başlatmanız önerilir.
